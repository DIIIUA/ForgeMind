Autonomous AI Engineering Station in Your Pocket

Автономная инженерная ИИ-станция для Android

ForgeMind unites all external and internal connections on Android: cloud frontier APIs, custom gateways with 4,000+ models, local LAN/Tailscale GGUF servers, Cloudflare Zero-Trust SSH, bidirectional MCP (:8765), dual-pane SFTP + Sora code editor, an 8-window ⚡ Turbo browser, and multi-window Android screen navigation.

ForgeMind объединяет все внешние и внутренние соединения на Android: облачные и кастомные API (включая агрегаторы на 4 000+ моделей без вылетов), локальные GGUF по Wi-Fi/Tailscale, Cloudflare Zero-Trust SSH, двусторонний MCP (:8765), двухпанельный SFTP и Sora Editor с откатами, 8-оконный ⚡ Turbo браузер и чтение/навигацию по окнам любых приложений Android.

Two Full Connectivity Contours

Два полноценных контура связности

ForgeMind is not limited to local LAN models or passive cloud chat — every external and on-device transport shares the same auditable execution engine.

ForgeMind не ограничен только локальными сетями или облачным чатом — все внешние и внутренние каналы работают через единый движок исполнения.

🌐 External ContourВнешний контур

  • 13+ Cloud Providers & Aggregators: OpenAI, Anthropic Claude, Google Gemini, OpenRouter, DeepSeek, xAI Grok, Groq, Mistral, Cohere, Together, Fireworks, Perplexity, Venice, and multi-thousand-model gateways.
  • Arbitrary Custom Endpoints: 6 auth modes (Bearer, x-api-key, api-key, query param, custom header), custom HTTP headers, and DNS-over-HTTPS bypass.
  • 1-Second Direct Host + /24 LAN Scanner: Instant connect to Tailscale/VPN/LAN IP:port for Ollama, LM Studio, llama.cpp, KoboldCpp, vLLM, Jan, OpenWebUI, and LiteLLM with live KV context detection.
  • Remote SSH/SFTP & Cloudflare Zero-Trust: Native JSch + WebSocket SSH (wss://) with CF-Access service tokens and zero open firewall ports.
  • External MCP Client: Connect remote tools over Streamable HTTP, SSE, and SSH stdio.
  • 13+ облачных провайдеров и агрегаторов: OpenAI, Claude, Gemini, OpenRouter, DeepSeek, Grok, Groq, Mistral, Cohere, Together, Fireworks, Perplexity, Venice и шлюзы на 1000+ моделей.
  • Любые кастомные серверы: 6 режимов авторизации, произвольные HTTP-заголовки и обход блокировок через DNS-over-HTTPS.
  • Точечное подключение за 1 сек + /24 LAN-сканер: прямой ввод IP:порт (Tailscale/VPN/LAN) и автопоиск Ollama, LM Studio, llama.cpp, KoboldCpp, vLLM с чтением реального KV-контекста.
  • Удалённый SSH/SFTP и Cloudflare Zero-Trust: нативный SSH поверх WebSocket (wss://) без белых IP и открытых портов.
  • Внешний MCP-клиент: подключение серверов по Streamable HTTP, SSE и SSH stdio.

📱 Internal Android ContourВнутренний контур Android

  • 4 File Environments + Sora Code Editor: Dual-pane file manager across App Sandbox, Phone Storage, Android SAF, and SFTP with TextMate syntax highlighting, unified diffs, and automatic pre-edit rollback snapshots.
  • Embedded Shell & Termux Bridge: Works out-of-the-box via persistent /system/bin/sh or pairs with local Termux sshd (127.0.0.1:2222) without bloating the APK.
  • Built-in Android MCP Host (:8765): Bearer-authenticated JSON-RPC 2.0 server exposing phone files, shell, browser, and UI tools to desktop IDEs or Termux agents.
  • 8-Window ⚡ Turbo Agent Browser: Isolated background WebView pool (browser_agent_batch up to 30 actions/turn) + whole-site Markdown scraper (web_scrape_site).
  • Multi-Window Android Screen Reading & Control: Reads UI trees across all open apps, enumerates windows, and acts via [#N] tags + floating overlay assistant & free Edge Neural TTS.
  • 4 файловые среды + Sora Editor: двухпанельный менеджер (песочница, память телефона, Android SAF, SFTP), подсветка кода, карточки diff и авто-снэпшоты отката перед каждой правкой ИИ.
  • Встроенный /system/bin/sh и Termux: мгновенная работа из коробки плюс бесшовная связка с локальным Termux (127.0.0.1:2222) без гигабайтного PRoot внутри APK.
  • Встроенный MCP-сервер телефона (:8765): защищённый Bearer-токеном сервер, открывающий инструменты смартфона для ПК (через adb forward) или Termux-агентов.
  • 8-оконный ⚡ Turbo браузер ИИ: пул фоновых WebView (browser_agent_batch до 30 действий за ход) и выгрузка целых сайтов в Markdown (web_scrape_site).
  • Чтение экрана любых приложений и навигация по всем окнам: разметка элементов тегами [#N], ориентация между окнами системы, плавающий чат поверх экрана и бесплатный Edge Neural TTS.

What's New in v0.2.1-alpha

Что нового в v0.2.1-alpha

⚡ 4,000+ Model Aggregator ReadyПоддержка каталогов на 4 000+ моделей

Eliminates duplicate-ID crashes (such as repeated aimlapi/dynamic-router entries) in both Chat and Settings pickers, merges metadata, caps category chips into virtualized LazyRows, and filters 4,000 models in milliseconds.

Полностью устранён вылет при открытии списков на 1 000–4 000+ моделей и дублирующихся ID (например, aimlapi/dynamic-router) в чате и настройках: умная дедупликация, виртуализация категорий LazyRow и мгновенный поиск.

🛠️ Universal GGUF Tool ExecutionИсполнение команд на любых GGUF

Parses 7 inline tool-call formats (including DeepSeek native Unicode/DSML, XML, Pythonic), repairs loose dicts, auto-downgrades wire history on HTTP 400/422/500, and nudges models that print raw shell blocks.

Парсинг 7 форматов вызовов инструментов, автопочинка словарей, автоматический обход ошибок Jinja-шаблонов HTTP 400/422/500 и автодоводка моделей, которые раньше просто печатали команды в чат.

📏 Live KV Context DetectionАвтоопределение окна контекста

Reads actual loaded context length from LM Studio (/api/v0/models), llama.cpp (/props), and Ollama (/api/show), with 1-tap Auto | 4K..1M override chips directly in the model switcher.

Автоматически считывает реально загруженное окно контекста с LM Studio, llama.cpp и Ollama и позволяет в один тап переключать Авто | 4K..1M прямо при быстрой смене модели.
