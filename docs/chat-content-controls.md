# Chat content controls — 0.2.8-alpha development

- The chat header magnifier searches the active branch, including reasoning. Matches are highlighted and arrows navigate individual occurrences, including repeats within a long reply and reasoning. The selected message temporarily displays raw text, including Markdown/code, so the exact matching character can be scrolled into view. Closing search restores formatted rendering and the original reasoning accordion. Up to1000 occurrences are shown per active branch to bound UI work.
- Drawer search scans titles and message/reasoning content from all chats, including archives and alternate branches. Results include a bounded excerpt. Opening an inactive branch selects the branch containing the result; a running agent in that chat must finish or stop first. Search is literal, case-insensitive for Unicode, and runs in cancellable pages off the UI thread.
- Select text and choose “Цитата”, or message overflow → “Цитировать и спросить”. The quotation is appended to the current chat draft. It is not sent automatically and command mode is disabled.
- Draft text, attachment references and command mode belong to each chat and persist locally. Attachment files are kept in their existing app storage; an asynchronous attachment import is bound to the chat where it began. Drafts are saved on an application-owned writer, with an extra flush when the activity stops. Drafts are local working text and are not included in chat ZIP exports.
- Message overflow → “Исключить из контекста” can omit that message or the whole user turn with its assistant/tool steps. History and branch links remain intact. The message shows its status and can be restored. Both changes reset the old compaction summary/checkpoints so excluded text cannot return from that summary. Tool-call batches and replies are omitted together. This changes future prompts; already performed tool actions and separate memory notes are not undone.
