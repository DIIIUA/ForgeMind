Setup guide

Мастер настройки

The guide opens on first launch and can be reopened from Settings. It remembers the current step, supports manual and automatic modes, and starts with Termux and Android permissions before models, MCP, voice, agent settings and appearance. Forms keep their explicit Save buttons. Automatic mode installs the bundled helper into its own Termux folder and installs only missing Python/tmux packages; changes requiring upgrades to existing packages stop for manual review. On Android 11+, the embedded ADB client supports one-time pairing through a notification and applies selected permissions with readback checks. Wi-Fi and Wireless debugging are required; root, a computer and a separate Shizuku app are not. Manufacturer restrictions may still require manual confirmation.

Мастер открывается при первом запуске и повторно из настроек. Он запоминает шаг, предлагает ручной и автоматический режимы и начинает с Termux и разрешений Android, затем ведёт через модели, MCP, голос, настройки агента и оформление. Формы применяются своими кнопками «Сохранить». Автоматический режим устанавливает встроенный помощник в отдельную папку Termux и только недостающие Python/tmux. Если нужны обновления существующих пакетов, установка останавливается для ручной проверки. На Android 11+ встроенный ADB-клиент позволяет выполнить однократное сопряжение по коду через уведомление и выдать выбранные разрешения с проверкой результата. Нужны Wi-Fi и беспроводная отладка; root, компьютер и отдельное приложение Shizuku не требуются. Ограничения производителя могут потребовать ручного подтверждения.

Models and connections

Модели и подключения

Five wire protocols: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini and Ollama Native. Cloud presets, custom HTTP gateways, multiple API keys, configurable authentication/headers/body, model discovery and large catalog search. Direct host connection and LAN discovery for self-hosted servers; context detection and manual overrides.

Пять протоколов: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, Gemini и Ollama Native. Облачные пресеты, собственные HTTP-шлюзы, несколько API-ключей, настройка авторизации, заголовков и тела запроса, обнаружение моделей и поиск в больших каталогах. Прямое подключение к серверу и поиск в LAN, определение окна контекста и ручная настройка.

Assistant profiles and instructions

Профили ассистентов и инструкции

Create, edit, search and categorize profiles with instructions, an optional provider/model and a history limit. Apply a profile to an existing or new chat. Base, global, chat and assistant instructions are composed in the system message; user instructions add to the base instruction. Profiles are preserved when switching models.

Создание, редактирование, поиск и категории профилей: инструкции, необязательные провайдер и модель, лимит истории. Профиль назначается новому или существующему чату. Основная, глобальная, чатовая и профильная инструкции объединяются в системном сообщении; пользовательские инструкции дополняют основную. Смена модели сохраняет профиль.

Scoped memory

Память с областями действия

Notes belong to a chat, assistant, folder, provider/model pair or all chats. Create, edit, enable, disable and delete notes; approved enabled notes enter the appropriate chat context within a budget. The agent can search memory and propose changes. Every proposal needs explicit human approval, including in autopilot; conflicting revisions are checked.

Записи для чата, ассистента, папки, пары провайдер/модель или всех чатов. Создание, изменение, включение, отключение и удаление; подтверждённые активные записи попадают в соответствующий контекст в пределах бюджета. Агент ищет память и предлагает изменения. Любое предложение требует явного подтверждения человека, даже в автопилоте; проверяются конфликты версий.

Local semantic search

Локальный семантический поиск

Search memory and tool descriptions by meaning using multilingual sentence embeddings. Optional distiluse-base-multilingual-cased-v2 model download (about 138 MB), ONNX Runtime CPU inference, vector cache, text/semantic/automatic modes and visible text fallback. Memory scope and enabled-state filters apply before ranking. Delete the model without deleting your notes.

Поиск по смыслу в памяти и описаниях инструментов через многоязычные эмбеддинги. Модель distiluse-base-multilingual-cased-v2 загружается отдельно (около 138 МБ), работает на CPU через ONNX Runtime, использует кеш векторов. Есть текстовый, семантический и автоматический режимы с явным переходом к текстовому поиску. Области и активность записей проверяются до ранжирования. Удаление модели сохраняет записи памяти.

Agent control and context

Управление агентом и контекстом

Queue a follow-up with «Дослать», intervene with «Сейчас», or stop a run while preserving saved partial output. Configure history limits, automatic/manual compaction, compaction prompt/model, threshold and preserved tail; restore a compaction checkpoint when compatible with current history. Model fallback includes approval and retry choices. The run/approval panel is available from the browser.

«Дослать» добавляет уточнение в очередь, «Сейчас» вмешивается в текущий ход, «Стоп» сохраняет уже полученную часть ответа. Лимиты истории, автоматическое и ручное сжатие, модель и инструкция сжатия, порог и сохраняемый хвост; восстановление контрольной точки при совместимости с текущей историей. Для запасной модели есть подтверждение и варианты повтора. Панель хода и подтверждений доступна в браузере.

66 tools and text tool calling

66 инструментов и текстовые вызовы

capabilities_catalog({}) lists every built-in tool by area in one compact call; area, name and query give details, full schemas and search. Tools of MCP servers are described by those servers through MCP. Native, automatic and XML/JSON modes support models without native tool calling. Explicit tool envelopes are parsed; fenced or inline code examples remain text.

capabilities_catalog({}) одним компактным вызовом перечисляет все встроенные инструменты по областям; area, name и query дают подробности, полные схемы и поиск. Инструменты MCP-серверов описывают сами серверы через MCP. Нативный, автоматический и XML/JSON-режимы позволяют работать с моделями без нативных вызовов. Разбираются явные блоки вызовов; примеры внутри блоков кода и обратных кавычек остаются текстом.

Terminal and command tasks

Терминал и задачи команд

Embedded Android shell, SSH and a direct Termux helper connection: live PTY input, resizing and Ctrl+C, multiple tabs, four arrow keys and confirmed /term chat commands. The helper uses a separate tmux server. ForgeMind sessions can be created, replaced and retained; these operations do not target native Termux sessions or existing servers. Commands have durable IDs, status, captured output and cancellation; a missing reply never means automatically replaying a command. The main app keeps its own UID and signing key. This connection needs no separate bridge APK.

Встроенная оболочка Android, SSH и прямое подключение к помощнику Termux: живой PTY с вводом, изменением размера и Ctrl+C, несколько вкладок, четыре стрелки и команды /term из чата с подтверждением. Помощник использует отдельный tmux-сервер. Сессии ForgeMind можно создавать, заменять и сохранять; первая пользовательская сессия Termux и работающие серверы не выбираются целью этих операций. Команды имеют устойчивые ID, статус, вывод и отмену; потерянный ответ не означает автоматический повтор команды. Основное приложение сохраняет собственные UID и подпись. Отдельный APK-мост для этого подключения не нужен.

Files, editor and rollback

Файлы, редактор и откат

Dual-pane files across app storage, shared phone storage, Android SAF folders and SFTP. Sora editor with TextMate highlighting; file search, code search, edit/append, tolerant replacement, unified patches and pre-edit snapshots. Cross-environment transfer, ZIP archives and text extraction from PDF and supported Office/OpenDocument files; send files into chat.

Двухпанельный менеджер: хранилище приложения, память телефона, папки Android SAF и SFTP. Редактор Sora с TextMate, поиск файлов и кода, правки и дополнения, устойчивое сопоставление замен, unified patch и снимки перед изменением. Перенос между средами, ZIP-архивы, извлечение текста из PDF и поддерживаемых Office/OpenDocument, отправка файлов в чат.

Browser, web and preview

Браузер, веб и предпросмотр

Separate user browser and up to eight agent WebView tabs with navigation, DOM inspection, actions, JavaScript, screenshots and batches of up to 30 steps. Turbo resource filtering, page/site extraction to Markdown, file downloads, five search backends and a local preview server. Browser navigation no longer recreates the surrounding screen or cancels generation on tab changes.

Отдельный пользовательский браузер и до восьми WebView-вкладок агента: переходы, DOM, действия, JavaScript, снимки и пакеты до 30 шагов. Фильтрация ресурсов Turbo, извлечение страниц и сайтов в Markdown, загрузка файлов, пять поисковых систем и локальный сервер предпросмотра. Навигация больше не пересоздаёт окружающий экран и не отменяет генерацию при смене вкладки.

SSH and bidirectional MCP

SSH и двусторонний MCP

SSH/SFTP with password or key authentication, including Cloudflare Access WebSocket SSH. MCP clients support Streamable HTTP, HTTP SSE and SSH stdio. An optional bearer-authenticated on-device MCP host exposes selected tools at 127.0.0.1:8765 with write/shell controls. Tool images are forwarded to supported vision models.

SSH/SFTP с паролем или ключом, включая Cloudflare Access WebSocket SSH. MCP-клиент поддерживает Streamable HTTP, HTTP SSE и SSH stdio. Необязательный MCP-хост телефона работает на 127.0.0.1:8765 с Bearer-токеном и настройками записи/оболочки. Изображения из инструментов передаются моделям, поддерживающим зрение.

Screen, voice and interface

Экран, голос и интерфейс

Optional Accessibility reads exposed Android window trees and numbered controls, performs actions/batches and captures screenshots on Android 11+. Floating chat overlay, notifications, speech input through Android/Groq/OpenAI/custom Whisper, and speech output through Android/Edge/OpenAI/XTTS. Theme and terminal palette customization; 14 locale resource sets with incomplete translation of newer dialogs.

Необязательная Accessibility-служба читает доступные деревья окон Android и нумерует элементы, выполняет действия и пакеты; снимки экрана — на Android 11+. Плавающий чат, уведомления, ввод голосом через Android/Groq/OpenAI/собственный Whisper, озвучка через Android/Edge/OpenAI/XTTS. Настройка темы и палитры терминала; ресурсы 14 языков, новые диалоги переведены ещё не полностью.

Chat organization and backup

Организация чатов и резервные копии

Chat folders, search, branching, attachments and Markdown export. Full ZIP archives include profiles, approved memory and proposals; selected-chat exports only carry chat-scoped memory. Archive format 3 reads older formats 1/2. Settings can be exported/imported separately with password-encrypted backup and an explicit import confirmation.

Папки чатов, поиск, ветки, вложения и экспорт Markdown. Полный ZIP включает профили, подтверждённую память и предложения; экспорт выбранных чатов переносит только память области чата. Формат архива 3 читает старые 1/2. Настройки экспортируются и импортируются отдельно: шифрование паролем и явное подтверждение импорта.

Releases before 0.2.5 used different signing certificates. Version 0.2.6 updates 0.2.5 in place. Export chats and attachments outside the app and verify a usable backup before reinstalling. Uninstalling deletes local app data. This release contains one public APK.

У релизов до 0.2.5 другие подписи. Версия 0.2.6 устанавливается поверх 0.2.5. До переустановки экспортируйте чаты и вложения вне приложения и проверьте пригодную к восстановлению копию. Удаление приложения стирает локальные данные. В релизе один публичный APK.

Know the limitsГраницы возможностей

Semantic search needs an optional ~138 MB model download; inference then stays on-device. Approved memory can be included in requests to your chosen LLM. No generative model or separate trained reranker is bundled. Background execution and screen control depend on Android permissions and OEM restrictions. New dialogs are not fully translated.

Для семантического поиска нужна отдельная модель ~138 МБ; после загрузки вычисления идут на устройстве. Подтверждённая память может входить в запросы выбранной LLM. Генеративная модель и отдельный обученный реранкер не встроены. Фоновая работа и управление экраном зависят от Android и прошивки. Новые диалоги переведены не полностью.
