# ForgeMind v0.2.9-alpha

Android10+ · versionCode11 · Room10 · ZIP5 (reads1–5).

## Fixed
- Explicit context settings for a model survive rediscovery and are used by generation requests. Quick provider creation records an explicitly edited context as a model override.
- Removed the hidden output-token halving rule. If a server rejects a request before streaming and reports exact prompt/context counts, ForgeMind retries once with a smaller output budget, including when extra JSON overrides the output field. No completed tool action is replayed.
- A manual context setting does not change the model server's own configuration. The server-reported context and native model capacity remain relevant.

## Included since0.2.6
- Reading controls, preserved answer variants, fragment branches and regeneration undo.
- Immediate voice input from the floating ticker before queued turns; cancellable model HTTP calls.
- Streaming speech, generation presets, scheduled prompts and schedule_manage.
- Editable tool arguments, scoped grants/revocation and cancellable destructive approvals.
- Archive comparison/reporting and backward-compatible Room migrations.
- Per-chat drafts, global and in-chat literal search with exact match navigation, quoting into a draft, and reversible context exclusions.

The release contains exactly one public release-signed APK. No personal, debug, test or companion APK is a release asset.
