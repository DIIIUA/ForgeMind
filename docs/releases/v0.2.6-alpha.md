# ForgeMind v0.2.6-alpha

Android 10+, versionCode 8, database schema 8. The release contains one public APK, `ForgeMind-v0.2.6-alpha.apk`, signed with the existing ForgeMind release key. It updates v0.2.5 in place. No personal APK, companion APK or test client is a release asset.

## Changes / Изменения

- A resumable first-run guide, with manual/automatic modes and a Settings entry to run it again. / Возобновляемый мастер первого запуска с ручным и автоматическим режимами и повторным запуском из Настроек.
- A bundled Termux helper: live PTY, files and tracked command tasks through an authenticated loopback connection. Its tmux sessions are separate from native Termux sessions. / Встроенный помощник Termux: живой PTY, файлы и отслеживаемые команды через локальное подключение с токеном. Его tmux-сессии отделены от обычных сессий Termux.
- Embedded Android 11+ ADB pairing through notifications, manual ports as a fallback, and permission grants checked against actual Android state. / Встроенное сопряжение ADB на Android 11+ через уведомление, запасной ручной ввод портов и выдача разрешений с проверкой состояния Android.
- Stable task IDs, no blind replay after a lost reply, explicit confirmation for file deletion, retained terminal sessions and updates to all current feature pages. / Устойчивые ID задач, отсутствие слепого повтора после потери ответа, обязательное подтверждение удаления файлов, сохранение выбранных сессий и актуализированные страницы функций.

## Boundaries / Ограничения

Termux must be initialized, `allow-external-apps = true` enabled, and command permission granted. Missing Python/tmux may require Internet access; existing package upgrades are left for manual review. Wireless debugging requires Wi-Fi and Android 11+. OEM restrictions and MediaProjection consent may still need system UI interaction. Reboot may require reconnecting services. The app does not reinstall/resign Termux, migrate to a shared UID, change SSH passwords or restart existing servers.

Termux нужно предварительно открыть, включить `allow-external-apps = true` и разрешить команды. Для недостающих Python/tmux может потребоваться Интернет; обновления существующих пакетов оставлены для ручной проверки. Беспроводная отладка требует Wi-Fi и Android 11+. Ограничения производителя и согласие MediaProjection могут потребовать системных экранов. После перезагрузки может понадобиться переподключение служб. Приложение не переустанавливает и не переподписывает Termux, не переходит на общий UID, не меняет SSH-пароли и не перезапускает существующие серверы.
