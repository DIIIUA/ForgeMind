# ForgeMind v0.2.5-alpha

## Русский

Исправительный релиз поверх 0.2.4-alpha.

- **Безопасность.** APK — релизная сборка без режима отладки, подписанная ключом релизов ForgeMind (SHA-256 `7ced078e33f7bf877763312f4992608dc183f82df3dfc3c09f288032eeb18ba8`). Ключ хранится вне репозитория.
- **0.2.4-alpha отозван.** Это была отладочная сборка: при USB-доступе к телефону с включённой отладкой её данные можно было прочитать. Перед установкой 0.2.5 экспортируйте чаты и настройки, удалите старое приложение, установите новое и импортируйте данные ([инструкция](../INSTALL.md)).
- **Каталог инструментов** `capabilities_catalog` описывает только функции самого приложения, одним компактным вызовом: все встроенные инструменты по областям, подробности по `area`, полная схема по `name`. Инструменты MCP-серверов описывают сами серверы.
- **Сжатие контекста.** Если автоматическое сжатие не удалось, чат не останавливается: работа продолжается без сжатия, ничего не удаляется, в чате показывается предупреждение с вариантами.
- Убрана документация о внутреннем устройстве сборки.

Один APK: `ForgeMind-v0.2.5-alpha.apk`, пакет `com.forgemind.app`, Android 10+, versionCode 7. JVM-тестов: 242.

## English

A corrective release on top of 0.2.4-alpha.

- **Security.** The APK is a release build (not debuggable) signed with the ForgeMind release key (SHA-256 `7ced078e33f7bf877763312f4992608dc183f82df3dfc3c09f288032eeb18ba8`), kept outside the repository.
- **0.2.4-alpha was withdrawn.** It was a debug build: with USB-debugging access to the phone its data could be read. Before installing 0.2.5, export chats and settings, uninstall the old app, install the new one and import ([guide](../INSTALL.md)).
- **Tool catalog.** `capabilities_catalog` describes only the app's own functions in one compact call: every built-in tool by area, details by `area`, full schema by `name`. Tools of MCP servers are described by those servers.
- **Context compaction.** A failed automatic compaction no longer stops the chat: the run continues uncompacted, nothing is deleted, and the chat shows a notice with the options.
- Build-internals documentation was removed.

One APK: `ForgeMind-v0.2.5-alpha.apk`, package `com.forgemind.app`, Android 10+, versionCode 7. JVM tests: 242.
