# ForgeMind v0.2.4-alpha

## Русский

Новый публичный релиз объединяет изменения после 0.2.1-alpha:

- Профили ассистентов: инструкции, категории, модель по умолчанию, лимит истории и назначение чату.
- Память чата, ассистента, папки, модели и общая память; изменения от агента подтверждаются человеком даже в автопилоте.
- Локальный семантический поиск по памяти и инструментам: необязательная многоязычная ONNX-модель около 138 МБ, кеш и текстовый запасной режим.
- Полный каталог 66 инструментов одним вызовом, XML/JSON-вызовы для моделей без нативных инструментов; кодовые примеры не исполняются.
- Команды `/term` из чата с подтверждением; управление отдельными сессиями, четыре стрелки, фоновые задачи со статусом, ожиданием и отменой.
- Улучшения «Дослать», «Сейчас», «Стоп», сжатия/восстановления контекста, инструкций и выбора запасной модели.
- Исправления белого окна браузера, пересоздания его верхней части и отмены генерации при переходах; панель агента и подтверждений в браузере.
- Передача изображений инструментов, восстановление соединения Accessibility, устойчивые правки файлов, архивы профилей/памяти и шифрованный перенос настроек.
- Обновлены сайт EN/RU, обе README, карта кода, каталог инструментов и инструкции установки.

**APK и переход:** обычный `ForgeMind-v0.2.4-alpha.apk` — `com.forgemind.app`; `ForgeMind-v0.2.4-alpha-side-by-side.apk` — `com.forgemind.app.public`, устанавливается отдельно. Оба из публичного исходного кода, без подключённых личных аккаунтов и без общего UID Termux.

**Старая подпись:** GitHub APK 0.2.1 был подписан ключом CI, отличающимся от нынешнего. Обновление поверх него невозможно. Сохраните старую установку, экспортируйте чаты, установите side-by-side и проверьте импорт. Не удаляйте старую до проверки данных. [Подробности и отпечатки сертификатов](https://github.com/DIIIUA/ForgeMind/blob/v0.2.4-alpha/docs/INSTALL.md).

## English

This release collects changes since 0.2.1-alpha: assistant profiles; scoped, human-approved memory; optional local multilingual semantic search; a complete 66-tool catalog; guarded XML/JSON tool calls; confirmed `/term` commands; managed terminal sessions and async task control; context/compaction recovery and fallback controls; browser/generation fixes; tool images; Accessibility reconnection; encrypted settings transfer and expanded archives. Both READMEs, the EN/RU website and architecture/tool/install documentation are refreshed.

The standard APK uses `com.forgemind.app`; the side-by-side APK uses `com.forgemind.app.public`. Both are public-source debug alpha builds, not shared-UID Termux plugins. The v0.2.1 GitHub APK has a different CI-generated certificate and cannot be upgraded in place. Keep it installed, export chats, import into the side-by-side version, and verify data before removing the old app. See [installation and signatures](https://github.com/DIIIUA/ForgeMind/blob/v0.2.4-alpha/docs/INSTALL.md).

## Validation and limits / Проверки и границы

- Public JVM suite: **241 tests, 0 failures/errors/skipped**; public APK assembly passed. SHA256SUMS and APK signature/package checks accompany the downloads.
- Public source and both APKs: **0 private-data marker / credential-pattern matches** in the release scan; generic library constants and synthetic fixtures were reviewed separately.
- Prior shared-feature validation: **59 emulator scenarios passed** (19 semantic/profile, 33 memory, 7 generation). Those scenarios ran on the separate Termux-plugin variant; this is not a claim of 59 fresh tests on each public APK. The public side-by-side build was installed and launched on a physical device with database migration/data preservation checked.
- Semantic model download is optional, about 138 MB; no generative model is bundled. Scope filtering precedes ranking. No separate trained reranker. New memory/profile dialogs are not fully localized.
- Background execution, Accessibility and Termux behavior remain subject to Android/OEM permissions and the selected route. Public standard APKs do not acquire Termux's shared UID.
- VersionCode **6**, Room schema **8**, archive format **3** (reads 1/2). Downgrading the APK does not roll back the database; retain pre-upgrade backups.
